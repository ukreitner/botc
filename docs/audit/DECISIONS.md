# Lead decisions on open questions raised by the audits (binding for implementers)

D1. ONE record type: `LedgerEntry` (records-and-memory) subsumes ChoiceRecord / NightRecord / DayEntry / DayAct / PublicStatement / PublicClaim. Add `byStoryteller: Boolean` (Goon needs it). `Memory.lastChoice(sourceId)` is DERIVED from the ledger, never stored.
D2. `ExecutionRecord`: day-engine shape (day, nomineeId?, outcome DIED/SURVIVED/NO_EXECUTION, via, diedInsteadId, tally snapshot) + optional `deathEventId` link. One execution per day is enforced from it.
D3. Status: status-model `Effect` (kind, source, target, until, endsWithSource) + `abilityWorks()` recursion. REJECT `PlacedReminder.inert`. Innate protections/poison (Tea Lady, Sailor, Innkeeper self, No Dashii, Vigormortis, Widow, Xaan) are StandingRules; grimoire tokens are RENDERED from effects. ST-placed `PlacedReminder`s remain as free tokens (with new payload fields: characterId, targetPlayerId, note, placedCycle) but never drive rules by label substring.
D4. Pukka: official reminders `["Poisoned","Poisoned","Dead"]` — two copies, NOT exclusive; new poison is placed before the previous victim dies; victim dies still poisoned (snapshot), then becomes healthy even if the death was prevented.
D5. Reminder labels: official Title Case from data-accuracy wins (e.g. "Survives Execution", "No Ability", "Died Today"). ALL code comparisons are case-insensitive on (sourceId,label); multi-copy tokens are listed N times in characters.json; data + code land in the same commit.
D6. Zombuul first death: `alive=false` + `DeathRecord(registeredOnly=true)`; kill() permits a real second death; WinCheck/night gate/grimoire badge read the flag. Dead players are nominatable (rules), so no special nomination path needed.
D7. Resurrection (Professor/Shabaloth/Bone Collector…): clears SPENT/once-per-game marks (Glossary), queues RUN_FIRST_NIGHT for "you start knowing"/first-night-only abilities, dawn announcement "X is alive again (don't say why)". Exception: Virgin's "1st nomination" is a historical fact — keep it spent.
D8. Alive counts: Mayor win counts Travellers; evil-wins-at-2 uses residents only; Scarlet Woman 5+ uses residents; 7+ minion/demon-info threshold counts non-traveller seats but the count is shown with a one-tap override.
D9. Night-1 "start knowing" tokens (Washerwoman Townsfolk/Wrong etc.): keep, dimmed as spent, clear on demand — not swept at dawn.
D10. Misregistration (Spy/Recluse/Lycanthrope Faux Paw/Revolutionary): `Effect(REGISTERS_AS)` + `LedgerEntry(kind=RULING)`; no invented "Registered: X" reminder pairs. InfoCalc returns typed `Answer` + `alternatives` (impaired / misregistration / Vortox-must-be-false are three distinct obligations).
D11. Impaired (drunk/poisoned) Vortox: loses the whole ability — Townsfolk info is not forced false and the no-execution loss does not apply; fix night_guide vortox.other.
D12. Vigormortis poisoned neighbour: engine offers both Townsfolk neighbours (rule ambiguous about skipping dead); ST picks.
D13. Chambermaid "woke": derived from the registry (NightAction kind ACT vs INFORMED vs NONE) with projection over the un-run tail of the NightPlan; per-character override lives in the registry, not characters.json.
D14. Countdown tokens (Courtier Drunk 1/2/3, Summoner/Xaan Night N, Leviathan/Riot Day N): advance at DUSK via a countdown TokenRule; labels follow official data.
D15. Minstrel: all-players DRUNK effects with until = dusk after next day, endsWithSource = false, plus a Prompt if the Minstrel dies mid-effect.
D16. NightStep holder identity: `StepKey(abilityId, holderId, variant)`; UI renders per-holder panels (drunk + real Empath, Village Idiots, Legion, Riot). Rename any `playerId` proposal to `holderId`.
D17. starPass/character change: one `changeCharacter(playerId, newId, reason)` — old character's sourced effects/tokens removed, alignment preserved unless the rule says otherwise, SPENT reset, pending-reveal queued, RUN_FIRST_NIGHT if the new ability is first-night/start-knowing, corpse's characterId cleared on star pass (token moves).
D18. Lil' Monsta `[+1 Minion]` = demon-for-minion swap (10p → 7/0/3/0); Kazali & Lord of Typhon bags have 0 Minions; Summoner bag has 0 Demons; Marionette must neighbour the Demon only when a Demon exists in the bag.
D19. Riot/Leviathan "each night choose an alive good player (different to previous nights)" jinx actions: implemented as jinx-gated NightActions active only when the jinxed character (Banshee/Farmer/Ravenkeeper/Sage) is on the script.
